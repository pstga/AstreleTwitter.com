🌌 AstreleTwitter.com
Un proiect de micro social media dezvoltat pentru cursul de Dezvoltarea Aplicațiilor Web (DAW).

AstreleTwitter este o platformă inspirată de Instagram, gândită pentru a conecta oamenii prin postări rapide, dar care aduce în plus funcționalități de management al grupurilor, integrare API pentru pasionații de astrologie și moderare automată a conținutului folosind Inteligența Artificială.

🛠️ TEHNOLOGII FOLOSITE
Backend: C#

Frontend: HTML, CSS

Integrare: API-uri externe pentru funcțiile de astrologie și AI

👤 CONTURI ȘI SOCIALIZARE
Autentificare și Înregistrare: Sistem complet pentru gestionarea conturilor.

Sistem de Urmărire (Follow): Urmărește alți utilizatori pentru a le vedea postările.

Confidențialitate: Setează profilul ca Public sau Privat.

Feed Personalizat: Un timeline dedicat unde vezi transmisiile prietenilor.

Căutare: Găsește utilizatori după numele complet sau parțial.

💬 INTERACȚIUNE ȘI POSTĂRI
Transmisii: Postează conținut și idei pe platformă.

Reacții și Comentarii: Lasă un like sau un comentariu la transmisiile altor persoane.

👥 GRUPURI DE INTERES
Creare: Orice utilizator poate forma un grup (ex: astrologie) și poate seta poza de profil a acestuia.

Administrare: Creatorul devine administrator, aprobă cererile de intrare și editează transmisiile membrilor.

Postări Interne: Membrii pot posta transmisii vizibile doar în interiorul grupului.

🤖 AI ȘI ASTROLOGIE
Moderare Anti-Hate Speech: Un companion AI detectează și blochează automat limbajul ofensator din postări sau profiluri.

Horoscop Zilnic: Introduci data nașterii, iar printr-un API gratuit afli zodia și cum îți va merge ziua.

🎨 DESIGN ȘI TEMATICI
Teme Custom: Schimbă aspectul platformei între o temă de zi și o temă de noapte (Night Mode) care are o estetică stelară/astrală.

⚙️ PANOU DE ADMINISTRARE (CRUD)
Superuser: Administratorul principal are acces la un dashboard complet.

Control Total: Poate șterge/modifica orice de pe site și poate oferi gradul de Admin altor utilizatori.
